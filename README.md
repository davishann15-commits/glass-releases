# Glass

A minimal, transparent Spotify client for macOS (and Linux).

**Download:** the `.dmg` from the [latest release](https://github.com/davishann15-commits/glass-releases/releases/latest). Drag Glass to Applications; the first time, open it from System Settings → Privacy & Security → *Open Anyway* (it isn't notarized by Apple).

**Updates are automatic:** Glass downloads new versions in the background and installs them when you quit (or at once with *update … · restart* at the top). Only updates signed with Glass's release key are installed.

This repository holds the released app only.
